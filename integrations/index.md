## Pas votre plateforme ?

Si vous utilisez une plateforme custom (Symfony, Rails, Django, Next.js, etc.), passez par un de nos [SDKs](/sdks/) directement. Vous avez le contrôle total sur l'UX checkout et la gestion des webhooks.

Pour les intégrations no-code (Zapier, Make, n8n, Bubble, Webflow), une connexion via webhook + API publique suffit. Voir [la référence API](/paiements/initialiser) pour les endpoints.
