# Shopify <span class="zd-tag soon">Bientôt</span>

L'app Shopify officielle Zayono est en cours de développement.

## En attendant

Vous pouvez intégrer Zayono manuellement avec Shopify via :

- **Shopify Functions + Webhooks** : implémentez votre propre passerelle custom avec un de nos [SDKs](/sdks/) et un endpoint payment-method-extension.
- **Shopify hosted checkout + redirect** : utilisez Shopify pour le panier et Zayono pour le paiement final via `return_url` / `cancel_url`.
